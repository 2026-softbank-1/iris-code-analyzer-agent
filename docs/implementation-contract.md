# Shared implementation contract (Iris deployment_v1)

Python 3.11+, dictionary JSON API with JSON Schema validation, canonical UTF-8 sorted-key compact JSON and SHA-256. Runtime dependencies: httpx, jsonschema, PyYAML, tree-sitter, tree-sitter-javascript, tree-sitter-typescript, python-dotenv. Dev: pytest, pytest-cov, ruff. Never execute analyzed repository code or load its OpenCode config.

## Ownership and APIs
- preprocessing owns src/iris_analyzer/preprocess/**; prepare_context(repo: str | Path, profile='deployment_v1', limits: Limits | None = None, excluded_paths: list[str] | None = None) -> dict ContextBundle. expand_context(bundle: dict, requested_paths: list[str], limits: Limits | None=None) -> dict. Snapshot bytes kept out of serialized payload in private registry keyed by snapshotId, immutable. save_bundle(bundle,out) writes manifest.json, context.json, evidence.jsonl and model-input.json. Limits import from iris_analyzer.contracts.
- contracts/result owns contracts.py, result.py, schemas/** and its tests. Limits dataclass fields max_bundle_bytes=180000, max_input_tokens=None, max_file_bytes=1000000, max_expansions=1, max_requested_files=5. AnalyzerError(code,message,details=None) stable public exception with .code and .details. canonical_bytes(obj)->bytes, digest(obj)->str. validate_bundle(dict)->dict, validate_reply(dict)->dict, validate_analysis(reply,bundle)->dict. static_analysis(bundle)->dict creates observed fallback; complete_for_profile recomputed after merge. Use dictionaries for integration; strict JSON Schema rejects malformed model output. Python snake_case functions, camelCase JSON.
- OpenCode owns opencode/** and transport/runner tests. ModelConfig dataclass and from_env(dotenv_path=None,**overrides); OpenCodeRunner(config).invoke_model(bundle)->dict synchronous public wrapper, call logs available as runner.calls. Provide HTTPX testability. Pin runtime version with actual /doc schema validation; include isolated server start helper if practical. API-key HIVE_AI resolves Hive provider only after actual docs discovery; no speculative endpoint. Allow env HIVE_BASE_URL,HIVE_MODEL,OPENCODE_URL,OPENCODE_PROVIDER,OPENCODE_MODEL. Integration orchestration root owns pipeline.py, cli.py, scripts/**, evaluations/**, pyproject.toml, README, CI, reports.

## Bundle
schemaVersion='1', preprocessorVersion='1', policyVersion='1', profile='deployment_v1', revision integer, source {snapshotId,commit:null|string}; manifest list [{fileId,path,size,digest,kind,eligible,exclusionReason:null|string}]; componentRoots list[str]; deploymentCandidates list[{candidateId,root,role,evidenceIds,componentRoots}], selectedFiles list[{fileId,path,role,selectionReason,providedRanges:list[{startLine,endLine}]}]; facts list[{key,value,scope,evidenceIds,component?:str,candidateId?:str,condition?:str|null}], relations list[JSON objects with evidenceIds], unresolved list[{key,reason,...}], coverage {providedEvidenceIds,omittedRelevantFiles,unresolvedReferences,truncated}; evidence list[{evidenceId,path,startLine,endLine,sourceDigest,contentDigest,redacted,text}]; contextHash (hash of all serializable bundle except contextHash; full manifest retained locally but runner sends compact selected subset). Bundle must not contain timestamps, local paths or private snapshot bytes. Additional coverage/policy/tokenizer fields permitted.

Facts use component=component root ('.', 'server', 'client'); scope='container'|'development'|'host_mapping'|'source'|'production'. Keys: runtime.name='node', framework='vite'|'express', build.command, start.command, output.directory, runtime.port, runtime.host, docker.workdir, healthcheck.path; environment.key string; api.route object {method,path}; frontend.connection object {baseUrl}; dependency.database object {name,engine}; dependency.volume object {name,mountPath}; package.name. Other keys allowed. Candidates map constituent components to deployed unit. Compose non-app databases are dependencies, not app services. No evidence-less detected facts. Semantic relationships can be explicit e.g. type='serves_static',from='server',to='client'.

## ModelReply / AnalysisResult
Reply {kind:'needs_files',requestedPaths:list[str],reason:str} or {kind:'analysis',result:AnalysisResult}. Result {schemaVersion:'1',status:'complete'|'needs_input'|'unsupported',sourceSnapshotId,contextHash,services:list,dependencies:list,apiRoutes:list,environmentKeys:list,connections:list,questions:list[{key,reason,kind:'code_review'|'user_configuration'}],coverage:{completeForProfile:bool,limitations:list[str]}}. Service {serviceId,root:Field,role:Field,runtime:Field,buildCommand:Field,startCommand:Field,outputDirectory:Field,workingDirectory?:Field,ports:list[Field],healthchecks:list[Field],componentRoots:list[str]}. Field {value:any,status:'detected'|'suggested'|'unknown',scope:str,evidenceIds:list[str],reason:str}; unknown value null; detected same value/key/component/scope in static observations; suggestions require existing evidence. Dependencies/routes/env/connections may be Field wrappers (route.value includes method/path/component); validate all evidence recursively. Observed facts are always merged, with conflicts becoming questions and preserving observed values. Do not infer auth from middleware name. Do not mark complete if mandatory items (role/root/build method, server start/container port or static output), unresolved or omissions remain.

## Final implementation notes

- Facts may carry candidateId, separating execution values when distinct Compose services share a build context. Component modules alone never define execution boundaries.
- The actual model-input.json in analysis revisions is the exact JSON text envelope containing responseSchema, contextBundle and responseTemplate; model-request.json preserves system text and the entire OpenCode request. Their independent digests are recorded. The compact ContextBundle contains the shared selected manifest and availablePaths view.
- Hive GLM uses verified json_text mode and strict schema/provenance validation. Native StructuredOutput is optional; its required tool call was rejected by Hive in the recorded probe.
- The fixed OpenCode agent uses steps=2 to avoid MAX_STEPS instructions on the first inference. Unpaid native request tests confirm one inference and no tools in json_text mode. Structured retries are zero. Budget reservation covers permitted steps, conversation growth and retries; missing prior structured-step usage is not refunded.
- Redacted mandatory execution values become unknown with user_configuration questions. Masked provenance is preserved; placeholders cannot become executable detected configuration.
- Snapshot ownership is reference-counted and synchronized. Pipeline releases on all outcomes; explicit prepare callers release their acquisition when expansion is finished.
- Library state events are the worker integration boundary; public HTTP/DB/source-transfer contracts are external team dependencies. Internal API paths do not promise public exposure or authentication.

Final Hive adapter sends the restricted proposal schema, native json_object mode, temperature 0 and low effort. Proposals may contain suggested/unknown fields only; detected observations are restored by the application. Service workingDirectory is optional runtime configuration and preserves docker.workdir independently of source/build root.
